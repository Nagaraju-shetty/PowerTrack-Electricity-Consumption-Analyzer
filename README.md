# ⚡ PowerTrack – Electricity Consumption Analyzer

PowerTrack is a web-based Electricity Consumption Analyzer developed to help users monitor their monthly electricity consumption, calculate electricity bills, maintain consumption records, and manage Gruha Jyothi Scheme requests.

## 🎯 Objectives

- Monitor monthly electricity consumption.
- Calculate electricity bills automatically.
- Maintain electricity consumption records.
- Allow users to apply for the Gruha Jyothi Scheme.
- Allow administrators to approve or reject Gruha Jyothi requests.
- Provide a simple and responsive web interface.

## 🏡 Gruha Jyothi Scheme

PowerTrack allows users to submit a request for the Gruha Jyothi Scheme.

The administrator can:

- Approve the request
- Reject the request
- Remove an approved scheme

After approval, the system applies the scheme according to the project's electricity consumption rules.

## 🔒 Security

## 🚀 Installation

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the `htdocs` folder.
4. Create the `electricity_analyzer` database in MySQL.
5. Import the project database.
6. Open the project using a web browser.

Example:

`http://localhost/electricity_analyzer/`
